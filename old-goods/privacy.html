本政策适用于《县城旧货店》Android TapTap 版本（包名 com.linhe.oldgoods.prototype）。本游戏由上述个人开发者运营。本政策说明游戏及接入的第三方服务如何处理信息，以及您如何联系我们、管理信息。

一、我们处理哪些信息

1. 本地经营进度与设置

游戏在应用私有目录保存经营天数、资金、货物、交易与街坊事件进度、随机种子、声音设置、隐私同意记录，以及用于故障恢复的一份存档备份。游戏业务代码不把这些经营存档上传到开发者服务器，当前没有云存档。

同一设备上的不同 TapTap 账号共用本地经营存档；切换账号不代表删除或切换经营进度。请妥善保管设备。

2. TapTap 登录

在您同意后，游戏调用 TapSDK 登录服务。SDK 在授权范围内处理账号标识与登录状态；本游戏申请 basic_info 授权，原生接入代码使用 OpenID 发起合规认证，不将该标识写入经营存档，也不把账号令牌、姓名或身份证号码发送给开发者业务服务器。

SDK 可能缓存登录状态以便后续登录。该缓存由 SDK 管理，不等同于本地经营进度。

3. 实名认证与防沉迷

游戏通过 TapSDK 合规认证服务判断能否进入游戏。必要时，平台页面可能要求您提供真实姓名、身份证号码等实名信息；这些信息具有较高敏感性，用于核验身份和实施防沉迷限制。请仅在平台提供的认证页面填写，不要通过游戏反馈或公开仓库发送。

本游戏业务代码只接收允许、受限、取消或错误等认证结果，不接收、展示或保存您填写的姓名和身份证号码。平台处理的账号、实名及认证相关信息，以其授权页面和隐私政策为准。拒绝必要的登录或认证将无法进入当前 TapTap 版本，已有本地进度仍予保留。

4. 您主动提供的反馈

只有点击“复制反馈”时，游戏才将您输入的描述、游戏版本、运行平台、经营天数和货源种子写入剪贴板。游戏不会自动发送反馈，也不会读取剪贴板里的其他内容。由您决定是否通过邮件或其他渠道发送。

当您主动联系我们时，我们会处理您的来信邮箱、问题描述以及自愿提供的附件，用于回复、排查和处理请求。请勿提供无关的身份证、账号密码或其他敏感信息。

三、存储、共享与保护

本地存档和设置保留在您的设备，直到您清除应用数据或卸载应用；重新开局会替换经营进度，备份文件可能仍保留前一份进度，因此重新开局不等于彻底删除所有本地文件。反馈来信只在解决请求及履行必要义务的范围和期限内保留，超出必要期限后删除或去标识化处理。

TapSDK 处理的信息由其提供方按照其政策管理，保存地点、期限及删除机制请查看第三方政策。我们不会将本地经营存档出售给第三方，不将用户信息用于广告画像。除实现已说明的服务、您主动选择的反馈渠道以及依法必须处理的情形外，不另行对外共享用户信息。

我们通过应用私有目录、必要权限限制和避免在业务日志输出账号凭据等方式减少信息暴露。设备遗失、系统损坏或未经授权的操作可能导致数据丢失，请保护好设备与平台账号。发生与我们处理信息有关的安全事件时，将采取必要补救措施，并按要求通知受影响用户。

四、您如何管理信息

  • 查看本地信息：游戏内可查看经营进度和设置。需要查阅、复制或更正反馈信息时，请联系上述客服邮箱。
  • 退出或切换登录：登录界面提供切换 TapTap 账号和保存退出功能。切换账号不会删除设备上的经营存档。
  • 撤回同意：您可停止使用并退出游戏，也可通过 Android 系统设置清除本应用数据，删除本地同意记录、设置与进度；再次启动时将重新征询同意。涉及 SDK 已处理的信息，可向我们或 TapSDK 提供方提出停止处理或删除请求。撤回不影响撤回前已依法进行的处理。
  • 删除本地数据：在系统设置中清除本应用数据，或卸载应用。该操作会删除本地经营进度，当前无法从开发者服务器恢复。
  • 平台账号与实名认证信息：本游戏未建立独立的开发者账号系统。TapTap 账号资料更正、注销及平台数据删除，请通过 TapTap 提供的账号管理或其隐私联系渠道办理；也可联系我们协助定位相应渠道。清除本地游戏数据不等于注销 TapTap 账号。

收到合理的信息权利请求后，我们会尽快核实并回复。核实仅限必要信息；若依法不能立即删除或满足请求，会说明原因。请勿在公开 GitHub Issue 中提交个人身份资料。

五、未成年人

未成年人应在监护人指导下阅读本政策，并按平台要求完成登录和认证。未满十四周岁的用户及其监护人应一并阅读 TapTap 的儿童个人信息保护规则，并按其流程取得监护人同意。游戏依据平台返回的认证结果限制进入，不提供绕过认证的入口。

监护人如发现未成年人未经必要同意向我们提供了信息，或希望了解、更正、删除相关信息，可联系上述邮箱；属于平台管理的认证信息，将协助转至相应平台渠道处理。

六、政策页面与更新

本隐私政策以 GitHub Pages 静态网页提供。阅读政策无需提交游戏账号资料，页面不加入广告、统计脚本或第三方字体。访问网页时，托管服务可能为网络服务和安全目的处理必要的访问日志；这与游戏经营数据上传不同，相关处理可查看 GitHub 隐私声明。

如游戏的信息处理目的、方式、范围或第三方服务发生重要变化，我们会更新本政策，并在游戏内重新提示、按需要重新征求同意。请以公开页面所列的版本日期为准。

引言

欢迎使用由 蜀都水獭工作室（以下简称“我们”）开发的单机肉鸽地牢冒险游戏《肉鸽：山海吞噬录》（以下简称“本游戏”）。

我们高度重视个人信息保护与用户隐私安全。本隐私政策旨在向您说明我们在您使用本游戏过程中如何收集、使用、存储与保护您的个人信息，以及您所享有的相关权利。

【特别提示】请您在下载、安装、注册、登录或使用本游戏前，仔细阅读并理解本政策的全部内容。当您选择同意或开始使用本游戏，即表示您理解并同意我们按照本政策处理相关信息。如您为未成年人，请在法定监护人的陪同和指导下阅读本政策。

一、适用范围

本政策适用于《肉鸽：山海吞噬录》移动客户端应用程序及相关服务。本游戏为纯单机核心体验的 Roguelike 地牢冒险游戏，所有关卡生成、战斗逻辑、怪物掉落、血脉吞噬与属性升级等核心玩法均在您的本地设备端运行。除提供 TapTap 账号登录、防沉迷合规核验及通关排行榜展示等必要平台互联服务外，不涉及与游戏玩法无关的数据收集。

二、我们收集与使用的信息

我们遵循“合法、正当、必要”原则，仅为实现本游戏的基本功能及合规要求处理必要信息：

1. TapTap 账号登录服务

  • 服务提供：本游戏账号登录由 TapTap 官方登录 SDK（易玩（上海）网络科技有限公司）提供。
  • 信息内容：当您选择使用 TapTap 账号授权登录时，TapTap SDK 会处理您的 TapTap 账号唯一标识、公开昵称及公开头像，用于确认您的用户身份并保持会话状态。根据 TapSDK 公式合规说明，SDK 还可为系统兼容与故障排查处理系统版本、设备型号、CPU 信息、网络类型、Android ID 和设备内存信息。
  • 开发者保护声明：本游戏自身代码不收集、不读取、不保存您的手机号码、短信验证码或登录密码。上述鉴权凭证由 TapTap 官方客户端与安全沙箱加密处理。

2. 防沉迷合规服务

  • 合规要求：根据国家防止未成年人沉迷网络游戏的相关规定，网络游戏用户须进行实名认证。
  • 处理机制：本游戏接入 TapTap 官方实名认证与防沉迷合规服务。实名认证流程由 TapTap 服务端依法收集并核验；SDK 可为系统兼容、故障排查与网络有效性检测处理系统版本、设备型号、CPU 信息、网络类型、Android ID、设备内存信息和网络状态。
  • 开发者保护声明：本游戏客户端及开发团队不收集、不读取、不存储您的真实姓名与身份证件号码明文。客户端依据 TapTap Compliance SDK 返回的合规状态（如：ALLOWED 放行 / RESTRICTED 限制游玩、剩余允许游玩时长）执行游戏准入、未成年人限玩和 fail-closed 控制。

3. TapTap 通关排行榜服务

  • 功能场景：当您在游戏中成功通关第15层终极试炼时，游戏会将您的通关成绩提交至 TapTap 官方排行榜服务。
  • 上传与 SDK 处理数据：本游戏业务层上传通关耗时（毫秒数）、通关积分及排行榜服务所需的 TapTap 账号标识。排行榜 SDK 还可为系统兼容与故障排查处理系统版本、设备型号、CPU 信息、网络类型、Android ID 和设备内存信息。
  • 账户隔离保护：本游戏在本地待上报队列中对用户信息采用不可逆的哈希算法派生安全标识（ownerKey），不将原始 OpenID 作为自定义追踪参数对外透传，保障数据隔离。

4. 单机本地存档与数据

  • 本地私有存储：您的地牢关卡进度、异兽血脉属性、装备道具、历史挑战记录等单机游戏数据全部保存在您设备操作系统的私有应用沙箱目录（/data/data/com.deng.shanhaidevour/files/）中。
  • 无云端同步：当前版本未接入云端存档同步功能，您的单机数据不会自动上传至外部网络服务器。

5. 关于遥测与数据统计的真实说明

本游戏当前未接入云端遥测或第三方用户行为埋点服务，开发者不为行为分析目的追踪您的游戏内操作轨迹。TapTap 登录、合规认证和排行榜功能中的必要数据处理，以本政策及《第三方 SDK 目录与个人信息共享公示》为准。

三、设备权限使用说明

为确保游戏基础运行与触觉体验，本游戏在运行期间可能申请或调用以下系统权限：

权限名称 权限类型 使用目的与场景 是否可关闭
android.permission.INTERNET 正常权限 用于 TapTap 账号授权认证、防沉迷状态在线校验、排行榜数据提交与查询 否（关闭后无法使用联网账号与排行功能；核心玩法为单机本地运行，实际离线可用范围取决于当前账号、合规状态及客户端已完成的校验状态）
android.permission.ACCESS_NETWORK_STATE 正常权限 用于检测设备当前网络连接状态（Wi-Fi/移动数据/断网），以感知网络波动并处理账号鉴权、排行榜提交或维持已授权的本地会话稳定运行 否
android.permission.VIBRATE 正常权限 用于战斗受击、暴击等场景的触觉震动反馈，提升游戏打击感 是（可在系统设置中关闭触觉反馈）

【明确排除说明】

  • 外置存储权限已彻底移除：本游戏已在 Android 清单中应用移除规则，彻底排除了 READ_EXTERNAL_STORAGE 和 WRITE_EXTERNAL_STORAGE 权限，本游戏及接入的任何 SDK 均不访问您手机中的照片、相册或外部媒体文件。
  • 零敏感危险权限：本游戏不申请、不调用读取手机状态（READ_PHONE_STATE）、定位（ACCESS_FINE_LOCATION）、相机（CAMERA）、麦克风（RECORD_AUDIO）、通讯录（READ_CONTACTS）或短信权限。

四、第三方 SDK 目录与数据共享

为保障产品功能的稳定实现，本游戏接入了必要的第三方 SDK。有关接入 SDK 的详细信息、收集数据类型及提供方隐私政策，请参阅附录《第三方 SDK 目录与个人信息共享公示》：

  • 主要第三方提供方：易玩（上海）网络科技有限公司（TapTap SDK，包括 Core、Login、Compliance、Leaderboard、ThemisLite 组件）。
  • 共享原则：我们仅在合法、正当、必要且明确的目的下共享最小限度的数据，且依赖第三方平台根据其自身隐私政策履行保护义务。

五、个人信息存储期限与安全防护

  1. 存储地点：依据中华人民共和国法律法规规定，本游戏境内运营过程中涉及的个人信息存储于中华人民共和国境内（具体由第三方 TapTap 平台依其隐私政策执行）。
  2. 存储期限：
    • 游戏内本地存档：保存在您的本地设备中，直至您主动卸载应用或清除应用沙箱数据。
    • 账号与排行榜数据：由 TapTap 平台在法律法规规定的期限内保存，直至您注销 TapTap 账号或排行榜周期维护。
  3. 安全防护措施：
    • 网络通信采用 HTTPS 传输加密。
    • 正式包启用 R8 压缩与混淆，并移除调试接口，以降低静态分析与非授权篡改风险。

六、用户权利行使

按照相关法律法规，您在个人信息处理活动中享有查阅、更正、删除等权利：

  1. 查阅与更正：您可通过 TapTap 客户端查阅或修改您的账号昵称、头像等个人资料。
  2. 删除与清除：您可以通过清除游戏应用沙箱数据或卸载本游戏彻底删除保存在本地设备中的所有单机游戏进度与排队数据。如需注销或删除 TapTap 账号数据，请按照 TapTap 官方指引操作。
  3. 撤回同意：您可以在系统设置中随时调整网络、震动等权限授权。

七、未成年人保护特别约定

  1. 我们高度重视对未成年人个人信息和身心健康的保护。
  2. 本游戏严格接入并执行防沉迷法定要求：
    • 依据 TapTap Compliance SDK 返回的合规状态，仅在周五、周六、周日和法定节假日每日 20 时至 21 时向未成年人提供不超过 1 小时的游戏服务；
    • 严格落实实名制，未实名认证用户限制进入；
    • 本游戏当前版本为完全免费单机体验，不开放任何应用内充值、虚拟道具购买或付费通道，杜绝未成年人非理性消费风险。
  3. 若您是未成年人的监护人，当您对所监护的未成年人使用本游戏有任何疑问时，请通过本政策列明的联系方式与我们联系。

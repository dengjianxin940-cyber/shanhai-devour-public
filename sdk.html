二、开发者承诺与特别说明

  1. 游戏客户端不接触敏感身份明文：
    • 玩家在使用 TapTap 账号登录时，手机号码、密码及验证码仅由 TapTap 官方登录组件在安全沙箱中处理；本游戏客户端不收集、不读取、不保存玩家的手机号与密码。
    • 玩家在实名认证与防沉迷流程中，接入 TapTap 官方实名认证与防沉迷合规服务，客户端依据 TapTap Compliance SDK 返回的合规状态执行游戏准入、未成年人限玩和 fail-closed 控制；本游戏客户端不收集、不读取、不存储任何身份证号码明文。
  2. 排行榜账号隔离与哈希机制：
    • 游戏内部采用基于 SHA-256 派生的 ownerKey 进行离线队列与用户数据隔离，不将原始 OpenID 作为自定义追踪参数对外透传。
  3. 外置存储权限彻底剥离：
    • 本游戏已在正式发布版本中通过 Android 清单规则明确排除了 READ_EXTERNAL_STORAGE 与 WRITE_EXTERNAL_STORAGE 权限，第三方 SDK 无法访问用户的设备相册或外部共享存储。
  4. 无外部遥测服务：
    • 游戏当前版本采用本地内存队列架构，不存在外部遥测服务器，第三方 SDK 亦未被授权收集任何游戏内单机战斗行为追踪数据。
